# 11.1131 - fix 48 source-confirmed tsc strict-type errors in 24 chart component files (chart bucket batch 11, second component batch)

## Scope

Second chart **component** source batch. 24 chart `.tsx` component
files holding 48 errors total (exactly 2 each). Every fix is PURE
TYPE - erased at compile, zero JS emission change, zero rendered
output change.

## Baseline (HEAD before this patch)

`tsc --noEmit -p web/tsconfig.json`: 330 errors total, 48 in the 24
target files (2 each).

Error mix (per the dispatch's category guidance):
- **TS2379 exactOptional** (most common): 24 sites with inline
  `{ X?: T; Y?: T }` option types in run/compute helpers. Fix per
  dispatch: add `| undefined` to each optional property of the
  TARGET parameter type in the same file.
- **TS7022 self-referential implicit any** (`const next = ...` /
  `const st = ...` ternaries that reference variables which can
  re-assign through the loop): 9 sites. Fix: explicit `: number`
  annotation to break the inference cycle.
- **TS7006 implicit any sort param**: 2 sites in chart-line-target.
  Fix: annotate `a, b` with the point type.
- **TS2532 possibly-undefined index access**: 2 sites in
  chart-line-tsne. Fix: non-null `!` on the indexed array element.

Total: **48**.

## After this patch

`tsc --noEmit -p web/tsconfig.json`: **282** errors total, **0** in
the 24 files. Delta = 330 - 282 = **-48**. Zero new errors anywhere.
`.test.*` files still at zero project-wide. Non-chart-component
files still at zero project-wide.
