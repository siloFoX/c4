Eighth batch of the chart showcase tsc-debt clear. 26 chart test
files holding 51 errors total (48 TS2532 in 24 chart-line files + 3
TS4111 in chart-donut + chart-tree-radial). Fix scope is ONLY the

target files.

## After this patch

`tsc --noEmit -p web/tsconfig.json`: **411** errors total, **0**
across the same 26 files. Delta = 462 - 411 = **-51**. Zero new
errors anywhere.

## What changed

Two minimal sed patterns:
- 24 chart-line files: `expect(buttons[N].getAttribute` ->
  `expect(buttons[N]!.getAttribute` (24 x 2 = 48 sites).
- chart-donut + chart-tree-radial: `.dataset.section` ->
  `.dataset['section']` (2 + 1 = 3 sites).

All fixes are runtime-equivalent (non-null assertion is safe after
the immediately-preceding `toHaveLength(N)`; bracket access on
`HTMLElement.dataset` is identical at runtime). No behaviour change,
no assertion change.
