# 11.1119 - fix 15 source-confirmed tsc strict-type errors in 15 test files

## Scope

15 test files (13 in `src/components/*` including 3 in `ui/`, 2 in
`src/hooks/*`) each holding exactly 1 strict-type error under
`exactOptionalPropertyTypes` / `noUncheckedIndexedAccess` /
`noPropertyAccessFromIndexSignature` / `noUnusedLocals`. Fresh
`tsc --noEmit` baseline confirms **15** errors across the same 15
files. All 15 are now fixed.

## Baseline (HEAD before this patch)

`tsc --noEmit -p web/tsconfig.json`: 806 errors total, 15 spread across
the 15 listed files (1 each):

- MeetingsDetailBody (TS2352 narrow conversion)
- MeetingsPeerRetroControls (TS2532 mock.calls[0])
- MeetingsRecapPanel (TS6133 unused `vi`)
- MeetingsView (TS2322 `MeetingSummary | undefined`)
- SessionsEmptyPanel (TS6133 unused `lastComparisonProps`)
- SpecialistsAddPanel (TS2345 `HTMLElement | undefined`)
- SpecialistsBulkOpsToolbar (TS2532 mock.calls[0])
- WorkerList (TS2783 duplicate `name` key in makeWorker)
- WorkflowNodeProperties (TS2379 `{ config: undefined }`)
- XtermView (TS2375 `visible: boolean | undefined`)
- ui/copy-button (TS6133 unused `act`)
- ui/export-button (TS2348 Mock not callable)
- ui/number-input (TS2375 8x optional `| undefined` props)
- hooks/use-a11y-ids (TS2353 `error` key on inferred initialProps shape)
- hooks/use-focus-cycle (TS2379 `onSelect: (...) | undefined`)

Total: **15**.

## After this patch

`tsc --noEmit -p web/tsconfig.json`: **791** total, **0** across the
same 15 files. Delta = 806 - 791 = **-15**. Zero new errors anywhere.

## What changed (per file, minimal)

- **MeetingsDetailBody.test.tsx** -- `as RecapResponse` -> `as unknown as RecapResponse` for the deliberately partial sample.
- **MeetingsPeerRetroControls.test.tsx** -- `mock.calls[0][0]` -> `mock.calls[0]![0]` after `toHaveLength(1)`.
- **MeetingsRecapPanel.test.tsx** -- dropped unused `vi` from vitest import.
- **MeetingsView.test.tsx** -- `searchResults: [SAMPLE[0]]` -> `searchResults: [SAMPLE[0]!]` (the literal `SAMPLE` array is statically known to have length >= 1).
- **SessionsEmptyPanel.test.tsx** -- removed the unused `lastComparisonProps` capture (declaration + write site + beforeEach reset). The mock still renders the same `<div data-testid="comparison-card">`.
- **SpecialistsAddPanel.test.tsx** -- `getAllByRole(...)[0]` -> `[0]!` (the `findAll` query has just returned a populated list).
- **SpecialistsBulkOpsToolbar.test.tsx** -- `handleImportFileMock.mock.calls[0][0]` -> `[0]![0]` after `toHaveBeenCalledTimes(1)`.
- **WorkerList.test.tsx** -- removed the duplicate `name: over.name,` key from the `makeWorker` helper. The trailing `...over` spread already supplies `name` (and is typed `& { name: string }` so it must), making the leading field a TS2783 duplicate.
- **WorkflowNodeProperties.test.tsx** -- replaced `makeNode({ config: undefined })` with an inline literal `<WorkflowNodeProperties node={{ id: 'n1', type: 'task', name: 'task one' }} />`. Identical runtime semantics (no `config` field -> `JSON.stringify(node.config || {})` renders `'{}'`).
- **XtermView.test.tsx** -- switched the renderView helper to conditionally spread `visible` only when defined (`...(over.visible !== undefined ? { visible: over.visible } : {})`) instead of passing `visible: undefined`.
- **ui/copy-button.test.tsx** -- dropped unused `act` from the testing-library import.
- **ui/export-button.test.tsx** -- `click()` -> `(click as unknown as () => void)()` for the captured `vi.fn()` mock whose `Mock<Procedure | Constructable>` type lost its callability under the current vitest typedefs.
- **ui/number-input.test.tsx** -- replaced 12x direct `prop={props.X}` passes with an inline `opt()` helper that conditionally spreads only when defined (same canonical exactOptionalPropertyTypes fix used in tag-input).
- **hooks/use-a11y-ids.test.tsx** -- cast the renderHook `initialProps: { id: 'x', helper: 'h' }` to the full union `{ id: string; helper?: string; error?: string }` so the later `rerender({ id: 'x', error: 'e' })` typechecks.
- **hooks/use-focus-cycle.test.tsx** -- `onSelect: onSelect | undefined` removed from the options object; spread `...(onSelect !== undefined ? { onSelect } : {})` instead.
