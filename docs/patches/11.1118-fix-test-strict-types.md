across the same 13 files. All 20 are now fixed.

## What changed (per file, minimal)

- **AutonomousView.test.tsx** -- dropped unused `within` from the testing-library import; removed the unused `lastMetricsProps` capture (declaration + write site + the beforeEach reset). The mock body still renders the same `<div data-testid="digest-metrics" ... />`.
- **ChatComposer.test.tsx** -- 2x `onKeyDown.mock.calls[len-1][0]` -> `onKeyDown.mock.calls[len-1]![0]` (`toHaveBeenCalled` guarantees length >= 1).
- **ControlPanel.test.tsx** -- removed unused `lastBatchProps` (declaration + write site + beforeEach reset); changed `runSingleMock.mock.calls[0][0]` -> `runSingleMock.mock.calls[0]![0]` (`toHaveBeenCalledTimes(1)` guarantees presence).
- **ErrorBoundary.test.tsx** -- typed the `Array.prototype.some` callback parameter (`(a: unknown) => ...`); added an explicit `ReactNode` return type to the local `NoMessage()` test component so its `never`-typed throw-only body is JSX-assignable.
- **MeetingsComposer.test.tsx** -- 2x bracket access on the captured `lastUseMeetingCreateArgs?.['onCreated']` and `?.['newTask']` (the captured shape is index-signature-typed).
- **MeetingsSearchFilterRow.test.tsx** -- 2x `mock.calls.at(-1)![0]` -> `mock.calls[mock.calls.length - 1]![0]` (`.at()` requires ES2022 lib not in the project target).
- **dev/GridDebugOverlay.test.tsx** -- 2x `vi.stubEnv('PROD', <bool> as unknown as string)` -> `vi.stubEnv('PROD', <bool>)` (the recent `stubEnv` overload accepts boolean directly for `'PROD'`; the cast was a leftover).
- **use-silent-poll.test.ts** -- removed unused `waitFor` from the testing-library import.
- **use-specialist-filter.test.ts** -- `{ stages: [] } as Specialist['triggers']` -> `as unknown as Specialist['triggers']` (the canonical "convert to unknown first" path for an intentional narrower-cast).
- **use-swarm.test.ts** -- `new Promise<HttpResponse>(() => {})` -> `new Promise<never>(() => {})` (the gate never resolves; `never` is assignable to any resolver return).
- **use-templates.test.ts** -- same `<HttpResponse>` -> `<never>` swap on a never-resolving fetch gate.
- **use-token-usage.test.ts** -- `urls.at(-1)` -> `urls[urls.length - 1]` (`.at` needs ES2022 lib).
- **use-workspace-prefs.test.ts** -- `getWorkspacePrefs().aliases.arps` -> `.aliases['arps']` (bracket access on index-signature property).
