# 11.1129 - fix 32 source-confirmed tsc strict-type errors in 32 chart showcase .test.tsx files (FINAL chart bucket batch)

## Scope

**FINAL** batch of the chart showcase tsc-debt clear. 32 chart test
files, exactly 1 error each (32 total). After this commit, **every
`.test.*` file project-wide is at zero tsc errors** -- the only
remaining errors are in chart component source `.tsx` files (out of
scope for the chart-tests campaign). Fix scope is ONLY the .test.tsx

target files (1 each).

- **21 TS4111** (`.dataset.section` -> `.dataset['section']`):
  chart-bubble, chart-calendar-heatmap, chart-circle-packing,
  chart-cluster, chart-dendrogram, chart-error-bars,
  chart-funnel-area, chart-histogram, chart-icicle, chart-marimekko,
  chart-pictogram, chart-polar-area, chart-radial-area,
  chart-radial-line, chart-radial-stacked-bar, chart-ridge,
  chart-slope, chart-spider-web, chart-streamgraph, chart-sunburst,
  chart-treemap-squarified.
- **8 TS6133** (unused helper):
  - `linearDown` (6): chart-line-dema-cross, chart-line-fractal-kc,
    chart-line-macd-cross, chart-line-supertrend-cross,
    chart-line-tema-cross-pct, chart-line-zlema-cross.
  - `WARMUP` (1): chart-line-volume-trend-cross.
  - `buildDeceleratingAfterPeak` (1): chart-line-cci-overbought-divergence.
- **3 TS2345**:
  - chart-line-band: `describeLineBandChart(null, null)` second arg
    `null` not assignable to bands `... | undefined` -> change to
    `undefined`.
  - chart-line-event: same shape (second arg null -> undefined).

Total: **32**.

## After this patch

`tsc --noEmit -p web/tsconfig.json`: **379** errors total, **0**
across the same 32 files. Delta = 411 - 379 = **-32**. **Every
remaining project-wide error is in chart component `.tsx` source
files; zero `.test.*` errors anywhere** (grep
`\\.test\\.(tsx|ts).*error TS` against the after log returns 0).

## What changed (per category, minimal)

1. **21 files** - single sed: `\.dataset\.section` ->
   `\.dataset['section']` (bracket access on index-signature
   property).
2. **8 files** - removed the unused helper declaration:
   - 6x `linearDown` constants (each used 0 times in their files).
   - 1x `WARMUP` const in chart-line-volume-trend-cross.
   - 1x `buildDeceleratingAfterPeak` function in
     chart-line-cci-overbought-divergence.
3. **3 files** - per-error fixes:
   - chart-line-band: `null, null` -> `null, undefined`.
   - chart-line-event: `null, null` -> `null, undefined`.
   - chart-line-fft-window: `w[w.length - 1 - i]` ->
     `w[w.length - 1 - i]!` for the `toBeCloseTo` argument.
