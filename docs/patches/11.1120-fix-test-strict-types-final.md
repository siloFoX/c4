**Final** batch of the test type-clean campaign. After this commit
the only remaining `tsc --noEmit` errors are inside
`web/src/components/ui/chart-*.tsx` (the chart showcase bucket), so
the build gate now collapses to a single chart policy decision.

15 test files (5 src/components + 10 src/lib) holding 16 strict-type

## What changed (per file, minimal)

- **ControlPanelBatch.test.tsx** -- drop unused `within` from the testing-library import.
- **HierarchyTree.test.tsx** -- drop duplicate `name: over.name,` field from `makeWorker`; trailing `...over` spread (typed `& { name: string }`) already supplies it.
- **HistoryView.test.tsx** -- drop unused `lastDetailPaneProps` capture (declaration + write site + beforeEach reset).
- **layout/FeatureSidebar.test.tsx** -- `buttons[0].textContent` -> `buttons[0]!.textContent` after `toHaveLength(1)`.
- **layout/FeatureView.test.tsx** -- `actual.FEATURES[0].Icon` -> `FEATURES[0]!.Icon` (the registry export is statically non-empty).
- **lib/i18n.test.ts** -- `window.localStorage.__proto__` -> `window.localStorage['__proto__']` (bracket access on the index-signature property).
- **lib/use-attach-process-state.test.ts** -- `params.name` -> `params['name']` (msw `:name` path param via index signature).
- **lib/use-audit-verify.test.ts** -- cast-init `let params = null as URLSearchParams | null;` so the inner closure's `params.get(...)` is not narrowed to `never`.
- **lib/use-meeting-template-editor.test.ts** -- `params.name` -> `params['name']`.
- **lib/use-profiles.test.ts** -- `new Promise<HttpResponse>(...)` -> `new Promise<never>(...)` (never-resolving fetch gate).
- **lib/use-risk-check.test.ts** -- cast-init `let receivedBody = null as { includeInspected?: boolean } | null;` so the inner `receivedBody?.includeInspected` is not narrowed.
- **lib/use-risk-stats.test.ts** -- same `<HttpResponse>` -> `<never>` swap on a never-resolving gate.
- **lib/use-scribe-context.test.ts** -- `setError.mock.calls.at(-1)?.[0]` -> `setError.mock.calls[setError.mock.calls.length - 1]?.[0]` (`.at` not in lib target).
- **lib/use-scrollback.test.ts** -- `'scrollback' as const` / `'screen' as const` -> `'scrollback' as 'screen' | 'scrollback'` / `'screen' as 'screen' | 'scrollback'` so the subsequent rerender with the OTHER literal still typechecks.
- **lib/use-stuck-meetings.test.ts** -- `<HttpResponse>` -> `<never>` swap.
