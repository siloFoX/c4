## What changed (per file, minimal)

All TS4111 errors are the same shape: a test asserts
`root?.dataset.<key>` after a `container.querySelector('[data-section=...]')`
hit. `HTMLElement.dataset` is an index-signature DOMStringMap, so
`noPropertyAccessFromIndexSignature` forbids the dot form. Fix is
pure bracket access -- no behaviour change, no assertion change.

- **chart-line-stoch-oversold-cross.test.tsx** -- 5x
  `dataset.length` / `kSmoothing` / `threshold` / `totalPoints` /
  `crossCount` -> `dataset['<same>']`.
- **chart-line-stoch-rsi-cross-sig.test.tsx** -- 6x
  `dataset.rsiLength` / `stochLength` / `slowKLength` /
  `signalLength` / `totalPoints` / `crossCount` -> `dataset['<same>']`.
- **chart-line-supertrend-cross-pct.test.tsx** -- 5x
  `dataset.length` / `factor` / `totalPoints` / `aboveCount` /
  `belowCount` -> `dataset['<same>']`.
- **chart-line-supertrend-cross-sig.test.tsx** -- 5x
  `dataset.length` / `factor` / `signalLength` / `totalPoints` /
  `crossCount` -> `dataset['<same>']`.
- **chart-line-volume-osc-cross-sig.test.tsx** -- 5x
  `dataset.shortLength` / `longLength` / `signalLength` /
  `totalPoints` / `crossCount` -> `dataset['<same>']`. Also removed
  the unused top-level `linearDownSeries` helper (TS6133); the
  parallel `linearUpSeries` helper is the only one still in use.
- **chart-line-zlema-cross-pct.test.tsx** -- 5x
  `dataset.length` / `lag` / `totalPoints` / `aboveCount` /
  `belowCount` -> `dataset['<same>']`.
